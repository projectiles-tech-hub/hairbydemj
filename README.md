# hairbydemj

Global online store for hair and hair accessories: website, staff admin
dashboard, and iOS/Android app, running on one custom-built backend.

- **Website:** hairbydemj.com
- **Admin:** admin.hairbydemj.com
- **API:** api.hairbydemj.com
- **Apps:** iOS (App Store) and Android (Google Play), built with Flutter
