# Module 3 — Accounts and sign-in

**Status:** Not started

## Goal

Secure customer and staff accounts, written in our own code.

## Steps

- [ ] Sign-up with email and password (scrypt hashing)
- [ ] Email verification codes
- [ ] Secure session cookies, sign-in and sign-out
- [ ] Forgot / reset password
- [ ] Google sign-in (OpenID Connect)
- [ ] Sign in with Apple (required in the iOS app when Google sign-in is offered)
- [ ] Linking Google/Apple and email logins to one customer
- [ ] Protection against password guessing and cross-site request forgery
- [ ] Staff accounts, roles, permissions and two-step verification
- [ ] Tests for every sign-in path

## Done when

Customers and staff can sign up, sign in, recover access and sign out safely,
and all tests pass.
