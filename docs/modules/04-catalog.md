# Module 4 — Catalog

**Status:** Not started

## Goal

Products, variants, hair attributes, categories and collections, managed
through the API.

## Steps

- [ ] Products with hair attributes (origin, texture, grade)
- [ ] Variants (length, density, colour, lace type, cap size, SKU, weight, dimensions)
- [ ] Inventory per variant with low-stock threshold
- [ ] Categories and collections (including rule-based collections)
- [ ] Shop-the-look sets
- [ ] API routes to list, filter, view and manage catalog data
- [ ] Tests

## Done when

Staff can create and manage the full catalog through the API, and customers can
browse and filter it.
