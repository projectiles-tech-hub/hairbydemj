# Module 6 — Cart and currencies

**Status:** Not started

## Goal

A cart that works in NGN, USD, GBP and EUR, with discounts and gift cards.

## Steps

- [ ] Prices per variant per currency
- [ ] Currency chosen from the customer's location, switchable by hand
- [ ] Cart for guests and signed-in customers (synced across web and app)
- [ ] Stock reserved correctly so the last item cannot be sold twice
- [ ] Discount codes and automatic deals, including combinations
- [ ] Gift card redemption
- [ ] Correct currency rounding
- [ ] Tests

## Done when

Carts total correctly in all four currencies with discounts and gift cards
applied, and stock is never oversold.
