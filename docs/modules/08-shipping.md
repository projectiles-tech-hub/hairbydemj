# Module 8 — Shipping

**Status:** Not started

## Goal

Live shipping rates, labels and tracking from DHL, UPS and FedEx, plus local
Nigerian delivery rates.

## Steps

- [ ] Package weight and size from cart contents
- [ ] DHL API: rates, labels, tracking
- [ ] UPS API: rates, labels, tracking
- [ ] FedEx API: rates, labels, tracking (including FedEx label certification)
- [ ] Local delivery rates set by staff in the admin
- [ ] Duties and taxes handling (once the owner decides)
- [ ] Tests

## Done when

Checkout shows live options with prices and delivery estimates, and labels and
tracking are created after payment.
