# Module 13 — Website

**Status:** Not started · **Depends on:** D3 approved, backend modules 1–12

## Goal

Every customer website page, built in plain HTML, CSS and TypeScript from the
approved designs.

## Steps

- [ ] Shared layout: header, footer, mini-cart, currency selector, cookie notice
- [ ] Shopping pages
- [ ] Checkout
- [ ] Account pages
- [ ] Information and system pages
- [ ] Search-engine basics (titles, descriptions, sitemap, structured data)
- [ ] Mobile-browser and accessibility checks
- [ ] Tests

## Done when

Every website page matches its approved design and works on desktop and mobile
browsers.
