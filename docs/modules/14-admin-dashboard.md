# Module 14 — Admin dashboard

**Status:** Not started · **Depends on:** D5 approved, backend modules 1–12

## Goal

Every admin page, built in plain HTML, CSS and TypeScript from the approved
designs, at admin.hairbydemj.com.

## Steps

- [ ] Staff sign-in with two-step verification
- [ ] Dashboard
- [ ] Products, product editor, categories, inventory
- [ ] Orders, order detail, returns
- [ ] Customers, discounts, gift cards, loyalty, reviews
- [ ] Homepage, content pages
- [ ] Shipping, payments and currency settings
- [ ] Reports, staff and roles, activity log, store settings
- [ ] Tests

## Done when

Staff can run the whole store from the admin, and every page matches its
approved design.
