# Module D1 — Brand and design system

**Status:** Not started · **Needs from owner:** brand assets (logo, colours, fonts) or approval for a proposed design

## Goal

One design system shared by the website, app and admin, so everything looks
like one brand.

## Steps

- [ ] Collect brand assets from the owner (or propose a direction for approval)
- [ ] Logo usage rules
- [ ] Colour palette
- [ ] Typography (fonts, sizes, weights)
- [ ] Spacing and layout grid
- [ ] Components: buttons, cards, form fields, icons, product-image style
- [ ] Build the design system in Figma
- [ ] Write the exact values into docs/design/design-system.md
- [ ] Owner approval

## Done when

The owner has approved the design system, and its values are recorded in
docs/design/design-system.md.
