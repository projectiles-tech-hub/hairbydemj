# Session 2026-11-10-01

Covers the design sessions from 2026-10-29 to 2026-11-10 (Module D1).

## What was done

- Owner chose to complete the design modules D1 to D5 before backend Module 2.
- Owner supplied the logo artwork (2026-10-30); colours sampled from it were
  adopted as the palette (2026-11-02), with a coral red added for errors.
- Fonts chosen after glyph tests (naira, pound, euro, dollar signs; Yoruba
  and Igbo letters): Source Sans 3 for body and UI, Cormorant Garamond for
  headings at 22 px and above.
- Figma file "hairbydemj Design System" built on `feature/design-system`:
  - Foundations: colour, spacing, radius, layout and motion variables, text styles;
  - Icons: Phosphor Light, 21 icons;
  - Components: Button (Primary, Secondary, Text; Default, Hover, Focused,
    Pressed, Disabled), Tag, Form field, Product card;
  - Logo: Primary, Mark, Monogram, Wordmark variants and App icon, traced
    into vectors from the artwork.
- Checked against WCAG 2.1 AA: all text pairings pass 4.5:1; deep gold is not
  used for text on espresso.
- Everything recorded in `docs/design/design-system.md`.
- Pull request #2 merged by the owner on 2026-11-10: Module D1 complete.
- End-of-session records updated on `docs/d1-session-close`.

## Decisions made

- Design first: D1 to D5, then backend Module 2 onward.
- Palette taken from the owner's logo; error colour coral red `#E5735F`.
- Fonts: Source Sans 3 and Cormorant Garamond.
- Icons: Phosphor Icons, Light weight (Fill for selected states).
- Motion: Material Design 3 timings and easing.
- Buttons fully round, labels in sentence case, 48 px minimum tap targets.
