# Session 2026-11-11-02

## What was done

- D3, D4 and D5 built in Figma on new pages Website, App and Admin:
  112 website frames (37 pages at desktop 1280, tablet 768, phone 390),
  43 app screens, 23 admin pages.
- Method: each approved D2 wireframe was copied, its kit parts swapped for
  design system components, and colours, text and corners set from the D1
  tokens and text styles. The home page hero was composed by hand.
- Design system extended: six solid supporting colour tokens (line,
  border-control, text-muted, surface-photo, surface-raised, gold-soft),
  shared page components (header, footer, app and admin shells, chip,
  stepper, checkbox, radio, photo placeholder, compact product card, list
  loader) and 20 icons.
- Checked by script on all three pages: no failing contrast, nothing under
  14 px, no colour outside the tokens, no text without a style, no wireframe
  parts left.
- Records: pages.md links and "In review" status for every page; one record
  file per module; pull requests #6, #7, #8.

## Decisions made

- One dark field (noir) throughout website, app and admin, with photographs
  and gold as the lit things on it.
- Solid tokens replace see-through ivory, blush and gold: the see-through
  versions did not hold inside component copies in Figma.
- Admin: flat outlined panels, plain tables, figures as type; gold only for
  the main action and money.
